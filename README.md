# LeaguePingo

LeaguePingo 是面向《英雄联盟》腾讯国服的桌面战绩助手原型，使用 Wails 3 beta、Go、Vue 3 和 TypeScript。当前优先开发 Windows；macOS 待 Windows 端成熟后适配，目前仅保留构建资源，不代表已经支持。代码托管于私有 GitHub 仓库，仍处于原型开发与国服实机联调阶段。

工程目录、平台边界及构建资源维护方式见 [工程结构](docs/PROJECT_STRUCTURE.md)。当前仓库仅保留 Windows/macOS 桌面目标；Android、iOS、Linux 产品模板及服务端部署模板已清理。

`dev` 已补充前端职责拆分、玩家标签键盘导航、设置焦点恢复及独立组件状态预览，使用方式和参考来源见 [前端迭代指南](docs/FRONTEND_GUIDE.md)。本批为源码改进，尚未生成新的 Windows 交付程序；下文 v9/v8 仍指此前已登记的本地程序。

开发前先阅读根目录 [AGENTS.md](AGENTS.md)：审批、架构边界、测试、交付与版本留存约定统一在仓库内维护。Windows 交付构建入口已收敛到 `scripts/build.sh`；这是一套可检查的开发流程，不是阻止手动调用编译器的安全沙箱。

## 当前功能

- 复制客户端完整 ID 时自动清理已知不可见方向标记和边缘空白，非法输入不发请求。身份查询使用客户端结构化“名称＋标签”接口并核验返回账号；超时/取消单独提示，不显示含玩家身份的原始请求 URL。
- 局内外均可输入完整 `玩家名#标签`，首次读取至多 20 场混合模式战绩；列表每页 20 场，面板内嵌上一页/下一页与指定页码跳转，按需读取并复用去重缓存，来源范围最多 1000 条。固定提供单双排、灵活排位、极地大乱斗、海克斯大乱斗等筛选，其他实际出现的模式补充展示。
- 大厅、排队、接受确认阶段准备客户端提供的房间成员；选人阶段读取可提供的本局名单，单路串行准备已知 PUUID。未知身份保留占位，不构造尚未确定的对手。
- 进入 `GameStart`、`InProgress` 或 `Reconnect` 时取消自动战绩预取，最多尝试三次本地名单刷新，补全客户端已提供的双方身份；取得完整十人名单和对局 ID 后停止自动名单刷新。
- 主窗口可“刷新对局名单”，也可选中已知身份玩家后“手动查询此玩家”。局内不自动补查新识别玩家的战绩，只有用户主动查询才发起请求；手动入口一次只处理一个操作，超时上限 12 秒。
- 全局 `Ctrl+Shift+P` 显示或隐藏快览。快览可拖动、隐藏、切换置顶，不提供鼠标穿透；资料查询和名单刷新在主窗口进行。
- 不注入游戏进程、不读取游戏内存、不拦截或代理游戏流量。
- 玩家战绩与当前对局分开；最多保留八个内存玩家标签、模式、分析场数、页码和展开状态。分析默认最近 20 场，可选 10/20/30/40/50，联动当前模式；胜率/KDA、近况、常用英雄共用分析样本，翻页不改变分析范围。未知字段显示 `—`，按有效分母统计，实际不足显示实际/目标数量，不冒称已取得完整目标场数。
- 切换模式、样本数或翻页时才按需补取；一次操作最多五次分页请求，15 秒后不再启动下一次请求，提供继续、停止与重试入口。战绩刷新使用已确认身份，只刷新首批历史，不重复名称查询或更新资料；刷新后样本不足可显式“补齐样本”，不会自动扫描历史。
- 页码支持输入后回车或点击跳转，非法输入不发请求；尚未查询的远页遵守同样的单轮限制，暂停后可继续目标页。页数只表示已找到范围，来源停止或离线时只能跳已有页；来源受限不等于账号没有更多战绩。
- 显式后续分页使用腾讯当前大区的 SGP 战绩服务；已在真实客户端核验 120 场不同比赛，新增记录包含灵活排位。LCU 在部分国服客户端会忽略起始位置，不能作为完整分页来源；SGP 不可用时降级为至多 50 场客户端混合记录，并明确提示受限，不误报账号无此模式战绩。首次显式远端分页另需核验大区、服务配置和当前会话，授权只在内存短时复用。
- 数据优先的深色桌面 UI：可收起导航、集中玩家资料、默认战绩行展示七个装备槽/两个技能；当前对局与快览双列对齐，十人快览常显胜率/KDA、样本数及五场近况。设计和布局验收见 [界面规范](docs/UI_DESIGN.md)。
- 本地中文英雄/装备/技能资源及符文名称；本玩家摘要包括时长、装备、技能、补刀、金币与伤害，展开可见客户端明确返回的地图/位置/符文/提前结束信号。后者不冒称确认重开，不自动排除统计。可点击“读取双方详情”请求整场参与者和装备技能；标准完整 5v5 且相关字段齐全时计算团队占比，接口兼容待国服实测。
- 可独立更新头像/等级/段位/隐私，不重拉历史。头像通过本地资源端点按已核验编号读取，失败显示占位；仅身份匹配且客户端明确返回 PUBLIC/PRIVATE 时显示公开/生涯不公开。资料按字段记录时间，更新失败保留的旧值明确标记，不推断隐私或未定级。
- 五分钟缓存、连接隔离、失败保留；首次已核验身份但历史失败也可保留玩家重试，不把错误带到其他标签。赛前轮询核验同连接账号变化并使旧缓存失效，局内不增加账号核验。
- 选人整次战绩准备最多 45 秒、每人两次，短暂阶段失败有界恢复，英雄变化不重置预算。阶段通知用于取消准备/唤醒核验；仅选人阶段另订阅选人会话，过滤名单/英雄变化，250 ms 合并后核验最新选择，保留约 3 秒轮询兜底；失败一分钟冷却，不订阅全量事件或增加局内自动历史。选人名单直接取 champ-select，不因 gameflow 人数相同忽略英雄变化。分页/双方详情仅显式请求，与查询共享调度。
- 名单/快览头像依次回退：本地英雄图标 → 已获取账号头像 → 人物图标；换英雄和后台刷新不额外请求资料。用户点击成员、“在战绩页打开”或手动查询命中历史缓存时，缺失头像/等级按需补取（最多 3 秒，不重拉战绩或段位）；已有基础资料复用，失败/缺失有 30 秒冷却，可点击“更新资料”主动重试。明确未选时显示“暂未选择英雄”，缺失字段显示“英雄信息暂不可用”，可见预选单独标注。
- 查询和玩家操作错误提示 150 ms 渐入，出现后 2 秒开始 200 ms 渐出并收起占用高度，再次触发重新计时；不清空已有战绩，持续连接/配置告警不自动隐藏，支持系统减少动态效果设置。
- 设置与诊断：窗口位置/大小和置顶记忆，可配置快览快捷键，显示版本/提交号；按需本地导出脱敏汇总，不上传。快览首次打开才创建第二个 WebView。

当前是可构建原型，**不是已完成国服实机联调的正式产品**。本机已验证客户端自动发现、阶段接口、自账号完整 ID 查询及 20 场战绩解析；曾在真实对局中确认本地 gameflow 接口提供双方各五个有效身份。新版从名单刷新到界面展示的整局流程、其他玩家的战绩可用性、隐私信号、不同模式，以及游戏内悬浮兼容性仍待实测。详见 [待解决问题](docs/OPEN_ISSUES.md) 与 [Bug 修复记录](BUGFIX_LOG.md)。

## 运行与构建

在项目目录使用 Bash（Windows 上使用 Git Bash）。Windows 完整验证/交付需要 Go 1.25+、Node.js 22+、Wails 3 CLI beta.29 和锁定的前端依赖；其他开发主机可显式运行通用验证子集。工具通过 PATH/环境变量或不提交的本机配置提供，见 [多主机环境说明](docs/ENVIRONMENTS.md)。

```bash
# 在配置好依赖的 Windows amd64 主机交付构建
# 入口会加载经检查的 .leaguepingo/environment.sh（若存在）
bash scripts/build.sh

# 远程或非 Windows 开发主机的显式子集，不等于交付验证
bash scripts/verify.sh portable
```

开发运行可用 `wails3 dev`。首次运行需已安装 Microsoft Edge WebView2。启动国服 League 客户端后，LeaguePingo 会发现 `LeagueClient.exe` / `LeagueClientUx.exe`，先尝试同目录的 `lockfile`，文件为空或不可用时改用 Windows 提供的客户端启动参数。也可设置 `LEAGUEPINGO_LOCKFILE` 指向测试用 lockfile。切勿提交、发送或记录 lockfile 内容或完整客户端启动参数，其中包含本地客户端密码。

本次已生成账号头像及提示动画修复测试版 `bin/leaguepingo-dev-20261018-v9.exe`，从干净工作区构建，内嵌功能提交 `c3b7849`，修复打开成员及命中战绩缓存时缺失基础资料的问题，增加错误提示渐入/渐出，并保留 v8 的选人同步与此前身份查询、SGP 分页功能。旧 v8 不包含本轮修复。仅本地交付，不创建 GitHub release；后续校验记录提交只更新文档，不更换该文件。使用前请从托盘菜单退出当前运行的旧版助手，包括 v8 和 `leaguepingo-dev.exe`；不需要退出游戏。新版采用固定应用标识的单实例策略：如果旧版未退出，启动新版只会唤起旧实例，不能热替换旧进程。更早的 `leaguepingo.exe`、`leaguepingo-fixed.exe` 没有该约束，也需手动退出。实际版本/提交号见“设置与诊断”。已进入对局时，新版会有限刷新本地名单，不会自动补查战绩；缺少战绩时在主窗口主动查询。

本轮测试文件 SHA-256：`e7f48c8a8c59cbbafcf81e98e8102d64f8e5f032338e437b1cb6260db87bc890`。此值仅核对上述本地文件；自行重建会嵌入新的时间，校验值可能不同。`scripts/verify.sh` 与干净提交上的 `scripts/build.sh` 均已通过；当前账号基础资料/头像的显式实机读取通过，但新版桌面显示、其他账号及游戏性能仍待验收。此前选人事件探测因不在选人阶段跳过，不把合成回归计为真实表现。重点复验步骤见 [实机验收](docs/ACCEPTANCE.md)。

Windows 完整验证：`bash scripts/verify.sh`。推荐上述 `build.sh`，运行绑定生成/构建/测试/静态检查与浏览器回归，嵌入当前提交号和 UTC 时间并输出 SHA-256。若系统 npm 缓存不可写，可用 `npm --cache .tools/npm-cache --prefix frontend ci`。避免覆盖被占用的旧版程序。可执行文件、诊断文件和测试截图不提交 Git。`main` 不改动，各改进批次单独提交推送 `dev`。通用子集明确列出未执行范围，不自动降级；所有进程检查/清理仅针对执行主机，不能清理另一台游戏电脑。

本地产物采用双版本留存：当前 v9 已完成本批用户验收，v8 作为回退版。后续 `build.sh` 默认使用唯一文件名，完整验证/编译成功后登记当前待验收版，自动永久清理更早的受管程序及证据；未验收版本的修复构建仍保留最近已验收版。运行中的旧程序跳过，不结束进程、不覆盖文件；构建失败不淘汰旧版。预览可运行 `node scripts/artifacts.mjs`。详细规则、验收登记和异常恢复见 [产物管理](docs/ARTIFACTS.md)。

`wails3 build`、`wails3 task build` 与 `wails3 task windows:build` 均调用统一交付脚本。`wails3 task run` 只读审计后运行清单中的当前程序，不再运行固定名称的旧文件。`node scripts/artifacts.mjs audit` 检查文件校验值、证据完整性、未知二进制和超额留存；未知文件只报错，不擅自删除。交付流程不支持 `DEV=true`、非 Windows/amd64 或额外编译标签；Wails 架构参数使用 `GOARCH`，不要使用会被其包装器覆盖的 `ARCH`。

热重载使用 `wails3 task dev` 或 `wails3 dev -config ./build/config.yml`，固定临时输出 `artifacts/hot-reload/leaguepingo-hot-reload.exe`，不登记或清理交付版本，与交付构建共享编译锁。该文件不可作为验收版。安装器/签名/Docker 和未适配平台入口当前明确拒绝，macOS 资源仍保留。工作流回归通过不代表热重载桌面或安装器已经实测；本批没有启动新助手。

关闭主窗口后助手会留在系统托盘；点击托盘图标可重新打开，托盘菜单提供“退出”。

## 快览窗口操作

- 拖动标题栏移动窗口；× 隐藏快览，窗口获焦时也可按 Esc；标题栏可切换置顶。
- 默认 `Ctrl+Shift+P` 显示/隐藏，可在“设置与诊断”更换；主窗口与托盘也可隐藏快览，不依赖快捷键。
- 已删除鼠标穿透、恢复鼠标的按钮/托盘项和 `Ctrl+Shift+O` 注册；快览一直接受鼠标操作。
- 快捷键注册失败会提示，可继续使用主窗口、关闭按钮和托盘。

## 本批验证

除 `go test ./...`、`go vet ./...` 与前端构建外，可按需执行：

```bash
# 隔离的隐藏原生窗口与双进程验证，不连接 League 客户端
LEAGUEPINGO_DESKTOP_TEST=1 go test . -run '^TestNativeDesktopSingleInstance$' -count=1 -v

# 显式选择执行：用当前账号验证完整 ID 到战绩，不输出账号数据
LEAGUEPINGO_LIVE_LOOKUP_TEST=1 go test ./internal/source -run '^TestLiveManualLookup$' -count=1 -v

# 显式选择执行：仅核验带复制方向标记的自账号 ID，不请求战绩
LEAGUEPINGO_LIVE_COPIED_ID_TEST=1 go test ./internal/source -run '^TestLiveCopiedRiotIDLookup$' -count=1 -v

# 仅选人阶段：有界读取名单并观察 8 秒选人通知；不选择英雄、不请求战绩
LEAGUEPINGO_LIVE_SELECTION_TEST=1 go test ./internal/source -run '^TestLiveChampSelectNotifications$' -count=1 -v

# 显式核验当前账号基础资料和头像，不请求段位或历史、不保存图片
LEAGUEPINGO_LIVE_PROFILE_TEST=1 go test ./internal/source -run '^TestLiveBasicProfileAvatar$' -count=1 -v

# 仅非选人/非正式对局阶段：有界验证真实后续页，输出计数而非玩家数据
LEAGUEPINGO_LIVE_PAGING_TEST=1 go test ./internal/source -run '^TestLiveHistoryPagination$' -count=1 -v

# 仅处于正在进行的标准 5v5 对局时执行：检查本地名单数量，不请求战绩
LEAGUEPINGO_LIVE_ROSTER_TEST=1 go test ./internal/source -run '^TestLiveRoster$' -count=1 -v
```

浏览器交互测试：在 frontend 目录执行 `npm ci` 安装锁定的依赖（包含 Playwright），设置 `BROWSER_EXECUTABLE` 为本机已安装的 Edge/Chromium 路径后，运行 `npm run test:smoke`。覆盖原有工作区/快览及分页/样本专项测试。也可用 `PLAYWRIGHT_MODULE` 指定已有 Playwright 包；不自动下载浏览器。需先构建前端，使用模拟绑定及合成玩家，不等同于真实游戏。统一构建自动将截图输出到对应版本的 `artifacts` 目录；单独测试时可指定 `UI_SCREENSHOT_PREFIX`、`WORKSPACE_SCREENSHOT`，路径按当前主机设置，后补证据需登记到对应版本，见产物管理说明。

默认 `go test ./...` 不连接真实客户端；上述实机检查必须显式启用。完整 ID 自账号查询已返回 20 场战绩；新版 `TestLiveRoster` 当时因对局结束而跳过，仍需下一局验证，不能将其计为通过。已经采集包含 WebView2 的短时离线内存/CPU 基线，详见 [性能验证](docs/PERFORMANCE.md)；未测游戏 FPS/延迟，不承诺零开销。

## 数据与隐私边界

“身份不可获取”仅表示当前客户端数据没有可用 PUUID，不能把它等同于玩家主动隐藏生涯。“查询失败”也不能作为生涯不公开的证据。界面把无法核验的生涯隐私状态标为“未核验”；识别“生涯不公开但身份已知”的可靠国服信号仍待实机验证，未完成前不会擅自贴标签。助手不持久保存查询到的战绩或玩家 ID，数据只保存在当前进程内。

非敏感窗口/快捷键设置存储在 Windows 用户配置目录的 `LeaguePingo/settings.json`；手动导出的诊断位于其 `diagnostics` 子目录，只包含固定类别计数/耗时/状态码与运行时信息。无自动遥测、上传或战绩落盘。静态游戏资源来源及发布前政策核验要求见 [第三方声明](THIRD_PARTY_NOTICES.md)。

显式后续查询会向已核验的腾讯当前大区 `*-sgp.lol.qq.com:21019` HTTPS 服务提交目标玩家标识和当前会话授权，这是战绩查询本身，不是遥测；不向第三方发送凭据。仅支持当前大区，不绕过服务端权限。自动准备仍使用 LCU，SGP 只用于主动分页；会话授权不传入 WebView、不存文件，换号清除。

架构与扩展边界见 [架构说明](docs/ARCHITECTURE.md)。
