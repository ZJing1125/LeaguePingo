# 对局玩家分析、五马评级与选人简报

2026-11-24，按用户确认的两份重构方案及六项订正实施规则v2。当前范围包括选人侧栏、对局室、加载/局内快览、冻结复盘和选人聊天。竞技场使用原名次分析，未知队列保留基础资料。旧v1归档按原0–10分解释，新报告使用模型版本4和百分制分析版本2。

## 统计样本与分档

分析取近30天、当前精确队列、按时间倒序最多15场有效对局，去重并排除重开、未来/过期记录及无完整K/D/A的记录。第1场权重1.5，每场递减0.05，第15场0.8，只对各场综合分加权一次。1–4场显示样本少和实际场数，至少5场才给正式马档。

| 百分制综合分 | 五马评级 |
| --- | --- |
| ≥85 | 千里马 |
| ≥72且<85 | 上等马 |
| ≥55且<72 | 中等马 |
| ≥40且<55 | 下等马 |
| <40 | 纯牛马 |

每个人按自身得分定档，同队可以全是中等马。队内相对名次只在详情单独展示。分数四舍五入一位后定档，未知不补零。覆盖未完整、峡谷缺实际分路或完整比较不足一半时保留低置信度；详情显示实际分项与各分项有效场数。

## 归一化和模式权重

参数在 `internal/core/horse_rules.json` 版本化维护。首版基准为60分，比例指标采用 `clamp(60 + 60 × (个人值/同组均值 − 1), 0, 100)`。经济转化率达到同组均值1.2倍时对应72分，可产生经济转化高标签；低于0.8倍对应48分。对位金币差按每分钟值计算，采用 `clamp(60 + 0.1 × 对位金币差/分, 0, 100)`。

比较优先同局同位置；没有可信位置时使用同主要英雄类别，并标低置信度。基准没有使用外部分段平均数据。金币不足1000、缺字段、均值非正和不完整阵容不能用作该项比较。具体斜率为首版规则参数，尚待国服样本校准。

| 历史对局位置/模式 | 指标权重 |
| --- | --- |
| 中/下 | 经济转化40%、KDA30%、对位金币差20%、参团10% |
| 上 | 对位金币差30%、伤害与承伤合计/金币30%、KDA25%、参团15% |
| 野 | 参团35%、KDA30%、对位金币差20%、经济转化15% |
| 辅 | 参团40%、视野/分30%、KDA30% |
| 大乱斗/海克斯/适用娱乐模式 | 伤害/分45%、KDA35%、参团20% |

缺对位金币差时，将其权重按原比例分配给经济转化与参团；其他缺失指标按剩余可用权重归一化。完整比较至少两项且可用权重不少于0.5。只有个人摘要时使用KDA参考，基准锚点峡谷2.5、娱乐3.0，标低置信度。原胜负/KDA基础模型只供旧归档及竞技场旧语义兼容。

## 标签和组队证据

聊天只取一项标签，优先级为当前英雄可靠记录、近期明显变化、位置表现、历史同队。侧栏展开可见完整标签和分项。

- 当前英雄近期至少8场且胜负完整时，展示实际场数和胜场，例如李青10场7胜。成就点数使用已有客户端资料，仅作为额外事实。满15场却未使用当前英雄时可写近15场未见本英雄。
- 连胜连败只看最近5场，至少4连胜或3连败时产生事实标签。
- 前后窗口完整时，以最近5场平均KDA对比此前10场。`ΔKDA ≤ −0.4`，且每10分钟死亡次数相对增加至少30%、绝对增加至少0.5次，同时满足才标近期死亡上升。
- 历史共现对照各玩家同一队列的最近15场，按比赛ID去重，目标阵营一致且至少2场时写近期同队X局。缺阵营不推断。当前来源显式同组字段在同阵营内匹配，可写客户端同组(楼层)；字段的国服组队语义仍待对照核验，SGP当前局补查沿用原加载/局内任务。
- 标签描述可核验事实，避免将连败、高死亡或没有近期英雄记录解释为玩家动机。

## 五秒冻结和发送

T0为首次识别到本次ChampSelect，在读取账号身份和名单之前启动计时。名单、位置、英雄与报告随原快照更新。选人只对实际我方身份启动独立游标，5路历史读取各自推进分页，其他阶段继续原2路，原总页数/阶段预算、取消与缓存规则继续执行。熟练度读数使用原有有界任务。

五席数据已就绪可提前冻结；否则T0+5秒冻结内存快照并入队。冻结不读取LCU阵容。冻结后正文不会被晚到数据或换英雄替换，侧栏继续更新。0/5表示没有可正式评级的席位，入队后跳过本局消息，晚数据不补发。匿名、未完成、样本少和已确认无公开历史分别表达；截止时尚在取数只写资料待取，不能据此断言隐藏战绩或网络超时。

聊天发现与资料读取同时开始，延续同一就绪聊天室的两次确认及750ms间隔。实际提交前由LCU发送器复核当前聊天室。各阶段耗时分别统计，150ms仅作为待实测传输对照，不把聊天室等待归为接口传输时间。

正文为UTF-8单行，上限256字节。楼层使用客户端cellId对应的0–9席位并在本队转换为1–5楼，位置只在峡谷模式显示；缺位置写待定。优先保留所有应展示席位、马档和实际场数，超限时省去可选标签。一次POST，失败/结果未确认不重发；离开选人、断线、换号或静音取消在途任务。全局开关默认关闭，支持队友/仅自己可见及包含自己。本局静音只作用于当前会话，新会话恢复全局设置。

## 观测与验收

诊断的analysisBrief包含readySeats、totalSeats、cachedSeats、freezeMs、queuedToPostMs、postMs及状态。固定匿名指标为brief/freeze、brief/queue-to-post、brief/post，消息正文、玩家身份和聊天室ID不写诊断。测试日志明确标明合成环境。

自动回归覆盖百分制基准/分界、同队同档、15场/30天/队列/重开边界、小样本、死亡变化双阈值、同队共现与对手区分、席位排序、5路并发、五秒部分覆盖、冻结后正文不变、0/5不恢复补发、静音/新局/取消、字节限制与280侧栏。`TestFiveSecondCoverage`使用实际5秒计时，分别记录5/5和3/5席的合成结果。

国服实机仍须核验缓存与冷启动第5秒的真实席位覆盖、cellId换位、聊天接收范围/提交结果、不同模式分档以及原生窗口体验。真实接口响应时长、五马参数分布、游戏FPS和网络RTT尚未实测。自动化、Windows候选发布和实机验收分别记录。
