## 统计样本与分档

分析取近30天、当前精确队列、按时间倒序最多15场有效对局，去重并排除重开、未来/过期记录及无完整K/D/A的记录。第1场权重1.5，每场递减0.05，第15场0.8，只对各场综合分加权一次。1–4场显示样本少和实际场数，至少5场才给正式马档。

## 归一化和模式权重

参数在 `internal/core/horse_rules.json` 版本化维护。首版基准为60分，比例指标采用 `clamp(60 + 60 × (个人值/其他可比玩家均值 − 1), 0, 100)`。经济转化率达到其他可比玩家均值1.2倍时单场分对应72分，低于0.8倍时单场分对应48分。对位金币差按每分钟值计算，采用 `clamp(60 + 0.1 × 对位金币差/分, 0, 100)`。15场加权均值再以60为不动点重缩放：`clamp(60 + scoreScale × (均值 − 60), 0, 100)`，scoreScale 当前为 3，综合分与分项均值同尺度。1.2倍稳定表现的最终分项分为96分，可产生经济转化高标签；0.8倍稳定表现为24分，可产生经济转化低标签。

比较均值排除目标本人。比较优先同局同位置；没有可信位置时使用同主要英雄类别，并标低置信度。基准没有使用外部分段平均数据。金币不足1000、缺字段和不完整阵容不能用作该项比较。参照均值明确为零时，双方均零记60分；本人正值而其他玩家均零时该项记100分，经济转化比例保持未知，避免除零和虚构倍率。比例斜率60和金币差斜率0.1继续使用。旧标尺把本人计入均值，对位1.5倍只得到72分；当前标尺同样表现单场90分，15场稳定表现重缩放后封顶100分，中性对照保持60分。该对照说明合成样本的区分度，真实分布仍待国服校准。

| 历史对局位置/模式 | 指标权重 |
| --- | --- |
| 中/下 | 经济转化40%、KDA30%、对位金币差20%、参团10% |
| 上 | 对位金币差30%、伤害与承伤合计/金币30%、KDA25%、参团15% |
| 野 | 参团35%、KDA30%、对位金币差20%、经济转化15% |
| 辅 | 参团40%、视野/分30%、KDA30% |
| 大乱斗/海克斯/适用娱乐模式 | 伤害/分45%、KDA35%、参团20% |

缺对位金币差时，将其权重按原比例分配给经济转化与参团；其他缺失指标按剩余可用权重归一化。完整比较至少两项且可用权重不少于0.5。只有个人摘要时使用KDA参考，基准锚点峡谷2.5、娱乐3.0，标低置信度。原胜负/KDA基础模型只供旧归档及竞技场旧语义兼容。

## 标签和组队证据

聊天每席最多保留三项符合条件的标签，按整体长度逐步降为两项、一项。侧栏展开可见完整标签和分项。综合分阈值负责分配个人五马档位，各战术标签另行核验触发依据。

- 院长级大腿需要综合分至少85、当前已知完整五人队内第一且至少五场有效分均伤害居首；靠谱火力点需要综合分至少72、至少五场经济转化证据均值达到对照的1.2倍。相对第一本身不触发这些标签。
- 场均死亡偏高要求综合分低于55、至少五场且平均死亡至少7。最近五场至少4连胜且平均KDA大于4时附带连胜/KDA标签；至少3连败且近五场场均死亡至少7时附带连败/死亡事实标签；至少3连败且五场参团率均已知、均值超过65%时附带实际连败和参团数据。

- 当前英雄近期至少8场且胜负完整时，胜率至少62%展示绝活英雄与真实样本胜率；至少10场且胜率不超过42%时以警示标记直接展示低胜率事实；其余展示实际场数和胜场。近期至少5场中当前英雄0场且已获取成就点数低于5000时合并展示0场与成就点数；否则成就点数作为额外事实，满15场未见当前英雄时写近15场未见本英雄。通用均衡或基础说明排在具体同队证据之后。
- 连胜连败只看最近5场，至少4连胜或3连败时产生事实标签。
- 前后窗口完整时，以最近5场平均KDA对比此前10场。`ΔKDA ≤ −0.4`，且每10分钟死亡次数相对增加至少30%、绝对增加至少0.5次，同时满足才标近期死亡上升。
- 历史共现对照各玩家同一队列的最近15场，按比赛ID去重，目标阵营一致且至少2场时写近期同队（已知有效楼层时附带对方楼层号，如`🔗近期同队(4楼·3局)`）。缺阵营不推断。当前来源显式同组字段在同阵营内匹配，可写客户端同组(楼层)；字段的国服组队语义仍待对照核验，SGP当前局补查沿用原加载/局内任务。
- 标签描述可核验事实，避免将连败、高死亡或没有近期英雄记录解释为玩家动机。

## 五秒冻结和发送

T0为首次识别到本次ChampSelect，事件回调直接启动单次计时，在读取账号身份和名单之前开始。名单、位置、英雄与报告随原快照更新。选人只对实际我方身份启动独立游标，5路历史读取各自推进分页，SGP历史通道6个请求槽（其他通道4槽），其他阶段继续原2路，原总页数/阶段预算、取消与缓存规则继续执行。熟练度读数使用原有有界任务。

五个物理席位使用固定槽位，cellId单独变化也提交新快照。至少一席身份已知，且各已知席均有15场有效样本或明确取数终态时可提前冻结；全匿名及缺席不提前冻结。评级前先完成所有可识别席位的数据状态判定。否则T0+5秒冻结内存快照并入队。每页提交在引擎锁内同步更新简报Frame和评级，Wails事件节流只影响界面推送。冻结不读取LCU阵容。冻结后正文不会被晚到数据或换英雄替换，侧栏继续更新。0/5表示没有可正式评级的席位，入队后跳过本局消息，晚数据不补发。匿名、未完成、样本少和已确认无公开历史分别表达；队列FetchStatus有pending、success、no-match-in-queue、timeout-or-error四个值。成功耗尽或已读到30天且本队列零场显示无本模式战绩；仍在取数显示资料待取；明确RequestTimeout显示网络超时/资料待取；其他错误显示资料暂不可用。已有有效评分继续保留。成功耗尽不推定服务覆盖了完整30天。

聊天发现与资料读取同时开始，延续同一就绪聊天室的两次确认及750ms间隔。实际提交前由LCU发送器复核当前聊天室。任务捕获非空发送接口，模式失效、关闭或代次变化取消在途任务，发送前仍检查代次与context。各阶段耗时分别统计，150ms仅作为待实测传输对照，不把聊天室等待归为接口传输时间。

正文为一条多行消息，包含LeaguePingo标题和按楼层排列的各席位，评级附带五马图标、有效场数与最多三项战术标签，不带玩家姓名。产品边界设为256个Unicode字符、最多1024个UTF-8字节、最多六行，超限时按三项→两项→一项逐步压缩。该数值是本项目的消息预算，国服实际接收上限仍待实测。发送校验只为该固定格式放行换行，其他控制字符继续拒绝；LCU收到一份JSON和一次POST，失败不拆条、不重发。

楼层使用客户端cellId对应的0–9席位并在本队转换为1–5楼。缺席保留资料待取占位，诊断分母固定5；关闭包含自己仅省略已知本人。身份不可用的席位保留状态行且无评级，峡谷缺本局位置写待定，其他模式省略位置。离开选人、断线、换号或静音取消任务。全局默认关闭，本局静音不修改下局配置。
