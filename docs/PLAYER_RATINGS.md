# 对局玩家分析、评级与选人简报

本批范围：同一套近期表现分析贯穿选人、游戏加载、局内快览、当前对局及冻结复盘；选人可显式开启自动发送我方五人简报；竞技场非五人队伍暂不开放自动聊天。评级每人独立，不强制五人各占一档。加载/局内默认展示历史近期表现；本局实时表现是另一项能力，不能混用名称。

## 数据与评分 v1

- 精确队列、近30天、真实已读范围；排位本季英雄信息继续独立。评分不要求凑足20场，不新增历史/逐场详情请求。
- 已返回的完整5v5对局按同分路比较；分路缺失或无分路时，使用同局同主要英雄类别，至少两名可比较玩家。分类取自Riot Data Dragon 16.20.1，与本地美术资源版本一致，主要类别不当作玩家实际分路。
- 每个指标是个人值/比较组均值，限0–2倍，乘5得到0–10分；数据缺失/组均值0时不计该指标。至少三项、原权重总和不少于0.5才使用完整比较。
- 常规权重：输出0.25、经济0.20、参团0.20、生存0.20、补刀0.10、视野0.05；峡谷辅助为0.10/0.15/0.25/0.20/0/0.30。
- 非分路一般类别：输出0.30、经济0.25、参团0.25、生存0.20；坦克增加承伤0.35；辅助类别增加治疗/护盾各0.15。具体归一化权重以performanceWeights为准。治疗取来源totalHeal，不能将其宣称为仅治疗队友。
- 生存用1/(死亡+1)，参团用(击杀+助攻)/本队完整击杀；不同定位不直接按绝对KDA排队。完整比较的单局分占90%，明确胜负占10%；未知胜负不补失败。
- 缺完整比较时使用暂定基础分：胜负占60%，KDA分占40%；缺一项按有效项归一化。KDA分=10*KDA/(KDA+锚点)，锚点峡谷/常规2.5、大乱斗3.0。这些是初始规则参数，尚未按真实国服样本校准，不声称为人口均值、胜率预测或其他产品评分。
- 竞技场只用已核验的名次与小队总数：10*(队数-名次)/(队数-1)；普通win不作夺冠依据。缺队数时保留原始名次统计，评级为资料不足。
- 近30天按7天半衰期加权；有效样本量n=(Σw)^2/Σw²，最终向中点5分收拢：n/(n+6)*均分+6/(n+6)*5。四舍五入一位后定级：S≥8.5、A≥7、B≥5、C≥3，其余D。真实0分保留，未知不补0。
- 少于5场、覆盖未完整、峡谷分路缺失使用类别替代或完整比较不足一半，标暂定/低置信度。完整覆盖且≥20场、有效样本量≥8、完整比较≥80%时可标较高置信度；不将队内第一描述为全服领先。

Data Dragon来源：https://ddragon.leagueoflegends.com/cdn/16.20.1/data/en_US/champion.json ，输入SHA-256 `84fd12721ea0cec502d2a747aea94d8e57d4da337422d1d3ca33a7890909787f`；仅打包英雄ID→主要类别，无玩家数据。

## 界面与阶段

卡片身份行显示评级/分数，保留236高快览及280/320侧栏。既有统计行可展示主要依据，详情提供分项、有效样本、规则和截止时间。两边所有已识别玩家均分析；对手未提供身份时保留未知。选人→加载→局内复用报告，追加样本按既有节流更新；查看其他模式只读对应缓存。冻结复盘不被下一局回填。

界面沿用品牌/字体和已有窗口，Taste data-terminal仅指导新分析数据的数字对齐、紧凑层级与证据邻近；不重建导航、不引入公共CSS或把本地设计工具提交到仓库。

## 自动聊天边界

独立开关默认关闭。用户开启后仅在ChampSelect向当前选人会话发送一次；可选我方全队可见/仅本机可见及是否包含自己。只用已经取得的统计，最多等待8秒；有部分可用评级时其余行注明资料不足，全无评级则不发送空分析，停止等待计时器，收到同一选人会话的新资料后恢复一次发送机会；不启动额外取数。

聊天使用固定LCU conversations/messages通道，不模拟输入，不在加载/局内聊天，也不新增玩家取数。选人会话、连接、账号或模式改变时取消旧任务；英雄/主题/统计参考切换不重复发送。发送前再次确认阶段和当前聊天室；POST尝试前占用一次性许可，错误不自动重发，结果可能已生效时明确提示待确认。消息正文、聊天室ID和玩家身份不进设置、诊断或磁盘缓存。

公开实现参考：[winer service.rs固定提交](https://github.com/sunerpy/winer/blob/4857f4830f5bd753ecf69266931199d94cd18584/crates/core/src/service.rs)（championSelect会话、chat/celebration消息）。仅参考本机聊天通道，未复用其评分；端点接受状态和本国服版本实际接收范围仍以PA3为准。

## 验证

必须分别验证计算规则/零与缺失/小样本/队列隔离、SGP/LCU派生字段、阶段复用/迟到隔离、自动聊天默认关闭/去重/取消/不重发、加载/局内双方展示、窄窗/两主题/236快览及Windows自动检查。所有消息测试仅模拟本机接口；当前Linux开发环境不代表国服实机发送或游戏性能已通过。
