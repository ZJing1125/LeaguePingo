# LeaguePingo 桌面界面规范

## 首页与外观（BUG-0048）

主窗口默认打开“首页”，横向导航为首页、对局室、玩家战绩。首页按已核验的当前账号显示账号头像、等级、完整 ID、单双排/灵活排位、首批最近 20 场的胜率/汇总 KDA/近五场结果、最近五条战绩和最多五位近期常用英雄；赛季胜负只用来源实际返回值，常用英雄明确为近期样本。点击完整战绩或记录进入已有战绩页，不自动翻页。连接未就绪、资料准备中、无历史、来源失败和断线保留分别显示，不假造段位、记录或评分。

外观命名为“浅色”“深色”“跟随系统”，不按时间强制切换。浅色沿用暖纸白/墨色/橙色；深色参考 OP.GG Desktop 的炭灰背景与紫色强调，胜负保留文字，主题不复制竞品品牌或素材。默认深色；已保存的浅色或跟随系统选择优先，未选择、无效配置或存储不可用时回退深色。顶部选择和设置里的三种预览都立即生效，本机持久化选择，跟随系统响应外观变化，窗口间同步。存储不可用时仍可切换并提示无法保存；首次绘制前解析选择，避免深色启动时闪白。局内快览保持深色，符合游戏中阅读需求。

主题覆盖标题栏、首页、导航、战绩、详情浮层、设置、输入、提示与禁用状态；对局卡按主题切换分区背景，玩家海报保留深色渐变保护文字。首页在 1280/1100 宽度使用段位、近期战绩、常用英雄三栏，880 宽度将段位和状态排到上方，下方内容自然滚动，不缩小关键文字。

## 视觉与信息层级（BUG-0045）

正式界面支持默认炭灰/紫色深色与暖纸白/墨色/橙色浅色，以横向导航组织首页、对局室和战绩。对局卡以用户图一的分区对照形式为准，主工作区保持清晰的文字、筛选和记录阅读。参考 [OP.GG Desktop](https://op.gg/desktop/en/games/lol) 和 [Porofessor](https://porofessor.gg/download) 的玩家信息层级，不复制其品牌、代码、专有评分或示例资料。未知值保留未知，胜负同时使用文字和颜色。

标题栏为 36px 无边框外壳，跟随玩家选择的浅色/深色，保留原生拖动、缩放、最大化／还原和关闭到托盘；导航提供首页、对局室、玩家战绩、完整 ID 搜索、主题、设置和手动快览。原生主窗口默认 1280×800，最小 880×620，旧设置中的有效尺寸保留。

## 对局室

我方和对方为上下两排英雄卡，每排正常五人，按来源顺序排列；不根据英雄猜位置或冒充同路对位，不显示未经确认的自身标记。额外成员换行且可以滚动，不裁掉特殊模式成员。房间阶段只显示真实成员，未确定的对手保持说明，不生成五个假玩家。

BUG-0049 按用户指定图一重做数据卡：头像、完整 ID/等级在顶部，青色/粉色分队线下并列英雄与段位；英雄区域显示本英雄样本、平均 K/D/A 与胜率，段位区域显示原创矢量徽章、实际段位/LP及返回的赛季胜负。移除原画覆盖层，以深蓝灰分区和固定对齐支持十人比较；浅色对应纸白分区。姓名及英雄保持截断/完整标题，未知与预选单独标注，已知零与未知分开。

中部三个圆环分别为近 12 小时、近期位置、近 30 天。两种时段只取已准备的最近最多 20 场、以历史获取时间为截止，明确显示样本场数及“近 N 场内”，不代表完整时段统计；没有获取时间或有效胜负时显示 —。近期位置仅取历史明确返回的峡谷 position，至少三场、唯一最多且占比不低于一半才展示，不从 lane/英雄推断，不当作本局位置，也不据此重排队伍。底部标签仅展示近况、连胜、本英雄/常用英雄场数、有效样本补刀每分等可核验事实，悬停说明分母；不伪造熟练度、地区排名或竞品标签。

房间没有选人时展示账号头像、等级及真实资料，不显示“英雄信息暂不可用”错误；房间成员按实际人数使用较宽卡片，未确定对手保持一条简短说明。选人/对局默认上下两组五卡，较窄窗口改三列并允许名单滚动。主卡高度 286px，压缩页面工具栏的空白以保留卡片空间，字段不会因选中而隐藏。

玩家详情通过覆盖式浮层打开，名单尺寸完全不变；Esc/关闭/遮罩返回原卡片，上一位/下一位便于比较，底部模式/场数与战绩页独立。浮层有焦点圈定与背景 inert，缩放不清空当前筛选。只保留一个“刷新数据”入口，同步更新历史和玩家资料；移除获取段位、更新资料等分散按钮。生涯状态只显示“生涯不公开”等简短文字；失败/旧值保留说明与字段时间，不解释客户端实现。

## 玩家战绩

左侧英雄海报和玩家身份/账号头像/等级/已知段位，右侧是实际分析样本、胜率、KDA、近期常用英雄和战绩。海报明确标为英雄背景，不冒充账号头像。没有当前英雄时使用当前分析样本中常用英雄背景，缺失资源回退本地图案。

保留最多八个内存标签、复制完整 ID、资料更新、历史刷新、模式、10/20/30/40/50 场分析样本、继续/停止、错误保留、内嵌分页/指定页跳转和显式双方详情。总体与本英雄统计共用所选模式最近的实际样本，翻页不改变分析样本。查询与本局详情的浏览状态相互独立，新局只重置本局详情。

1280×800 首屏至少五条完整记录，1100×760 至少四条；默认展示七个装备槽和两个召唤师技能。来源受限不等于没有该模式记录；不足场数如实显示实际/目标，不能用其他模式补数。切人或隐藏工作区停止后续扫描。

## 两种快览

默认 1100×640 的深色快览为上下两排、每排五人，使用同一份分区卡和统计，卡高 236px，缩减辅助层并显示最多两个事实标签；不根据横向列声称实际位置匹配。最小 400×360 可纵向滚动，680px 以下改为紧凑两列；不为挤进十人而制造横向裁切。

- 临时：默认按住 Esc 下方的 `~`/反引号物理键（无需 Shift），松开隐藏；可在设置选择 F8/F9/F10 或关闭。仅连接中、InProgress 且实际 League of Legends.exe 窗口在前台时有效。鼠标和原始按键继续交给游戏，快览没有操作按钮，不抢焦点。切出游戏、离局、断线、改键、禁用或退出清理临时状态，首次创建期间松键也不迟到显示。
- 手动：按钮或 Ctrl+Shift+P 显隐，可交互、拖动、Esc 隐藏、切换置顶。置顶只表示 always-on-top；松开按住键不关闭手动快览。临时快览使用游戏所在显示器，隐藏后恢复手动窗口保存的位置/大小。

显示/隐藏均只读取缓存，不请求战绩、段位、头像或后续页，不重置每局的一轮补齐。按键冲突由用户在设置改键，不抢占游戏绑定；建议无边框/窗口模式。独占全屏、Windows DPI、多屏和游戏焦点的最终表现仍需实机验收。

## 素材、反馈与可访问性

173 张经典英雄载入原画与现有雪碧图一同打包，无运行时 CDN/字体请求。来源、体积与 SHA-256 在 portraits/manifest.json；维护脚本显式运行，不进入应用启动或构建。新增英雄缺图使用回退。游戏素材权利见 THIRD_PARTY_NOTICES.md。

玩家标签保留方向键、Home/End、Delete；设置与窄窗详情有焦点圈定和返回。按钮提供中文名称及可见焦点。暂时错误沿用渐入、两秒计时、渐出收起及减少动态效果设置；持续配置/连接告警常显。界面不以渲染、悬停或快览显示触发数据补取。

浏览器使用模拟桥接与合成资料，不代替 Wails 原生、真实账号、整局或 FPS/延迟验证。检查命令与边界见 FRONTEND_GUIDE.md、ACCEPTANCE.md。
