# LeaguePingo 桌面界面规范

BUG-0138：资料页采用“本局模式 · 自动”紧凑选择器，可查看其他模式参考；攻略始终跟随本局。排位英雄展示本季，非排位展示近30天。海克斯/普通大乱斗移除位置环，时间窗口改两列，段位为次级排位参考；只展开用户选择的卡片。沿用主题、字号、头像及280/320侧栏和236高快览尺寸。竞技场显示独立有效样本的夺冠率/平均名次，缺失不补0；详情按名次列人，不套红蓝5v5。信息顺序与MS1–MS7验收见MODE_SCOUTING_PLAN。

BUG-0113：游戏辅助设置读取期间显示“正在读取设置…”，读取失败显示未读取并给出手动重试；初始默认值不能冒充已保存值。配置控件在读取和保存期间暂停编辑，保留工作区导航，不新增弹窗/常驻横幅，不为重试发送自动化动作。

U7：交互控件、summary、链接和可键盘滚动区域都应有至少2px可见焦点；记录行与滚动容器使用内收边框，避免overflow裁切。浅色强调/胜负语义色略加深，保留纸白/橙色和深色/紫色方向；小字至少4.5:1、焦点至少3:1。键盘路径与当前测量见[ACCESSIBILITY.md](ACCESSIBILITY.md)，减少动态效果规则保留。

BUG-0075：沿用强化比较布局，竞技场用推荐/品质与来源胜率/场数，海克斯仍用梯度/品质/表现分。轮换模式显式展示来源页版本参考，防止旧资料被当成本局最新攻略。

BUG-0073：海克斯强化列表使用梯度、名称、品质和中文效果；主窗双列、280侧栏单列。三个候选在主窗/快览并排、侧栏纵列，搜索和品质控件紧邻列表；分值仅标表现分/热度分。原有主题/字号与十人快览容量继续保留。

BUG-0071/0072：玩家姓名旁显示同组匿名码与人数、当前对局显示字段覆盖；国服含义待核验。当前对局提供英雄攻略，侧栏玩家资料/攻略切换，快览只读缓存摘要。使用既有主题与官方装备/符文图标，样本与来源可见、未知不补零，280窄侧栏竖排、880主窗无横向溢出。详见HERO_GUIDES/PREMADE_GROUPS。


## BUG-0070 赛后返回与排队反馈

游戏辅助增加赛后返回与下一局设置，说明只有单人/队长就绪才自动排队。主界面和展开侧栏共享等待结算、返回倒计时、等待队友/队长、排队倒计时、完成/取消/未确认状态。等待和倒计时提供取消本次，失败不显示成功；只开排队时明确需手动返回房间。沿用紧凑状态条、主题语义色和12px数字读数。

## BUG-0069 自动接受反馈

游戏辅助设置中增加自动接受开关及延迟，显示实际生效值，默认关闭。主界面状态区和已展开侧栏以紧凑单行显示后端实际状态，倒计时提供“跳过本次”；最窄侧栏可换行。沿用主题语义色、12px辅助文字、数字等宽和可见焦点，不新增弹窗、不抢焦点。未确认结果提示到客户端检查，不把超时当成功。

## BUG-0068：首页英雄信息与战绩纵向节奏

首页左列按段位、当前状态、位置与时段、常用英雄、英雄熟练度排列。常用英雄属于当前战绩分析样本，放在全部模式熟练度之前以便比较，但两者口径保持独立。右侧不再在战绩下重复放英雄表；最近战绩不设固定高度或内部滚动，每页20场自然展开并由首页整体滚动。筛选和翻页后回到战绩区顶部。窄窗中常用英雄必须位于熟练度上一行，主列和控件不得横向裁切。

## BUG-0067：当前对局与最近复盘

对局室顶部提供“当前对局 / 最近复盘”。房间、选人、载入及局内默认显示当前阶段的已准备资料；没有赛后记录也能展示。房间/选人仅我方，不画敌方占位；加载/局内按已返回名单展示双方，缺失显示等待，断线保留已准备值。当前排位切换与侧栏/快览同步。上一局复盘独立保留，其中“赛前资料快照”明确为归档；其切换不改变当前数据。新房间、新局及进入加载返回当前，重复快照不覆盖用户手动选择；首页“查看当前对局”优先于旧复盘。

复用现有三圆环卡、真实准备进度、玩家浮层、深浅主题及C款标志。打开当前卡片只读已准备资料，查询最新战绩为单独明确操作。此条替代BUG-0054主程序只用于赛后的页面限制，侧栏和轻量快览继续承担自动辅助展示。

## BUG-0059：专业概览与单场复盘

九张参考图的逐项分析与数据范围见 [PLAYER_ANALYSIS.md](PLAYER_ANALYSIS.md)。首页使用紧凑账号横幅、左侧排位/位置时段/熟练度与主列近期比赛/战绩/英雄表；保留当前主题和高清原画。排位显示实际官方图标、各队列胜负和真实最高/上季记录；没有完整多赛季轨迹时不绘制虚假历史。常用英雄提供近期样本/近7天已读切换、英雄搜索、胜负条、KDA与CS/分，和全部模式熟练度分开。

查询页身份摘要置顶，左列按内容高度滚动，不压缩段位与熟练度；右列默认使用可展开分析摘要，优先连续战绩，展开后显示胜率环/平均KDA/参团/英雄与位置图。紧凑战绩行保留英雄等级、双技能/主副符文、七装备、KDA、CS/分、参团与双方阵容；窄列保留阵容图标和名称悬停，保持至少11px辅助字号。模式/样本/分页与跳页仍沿用原浏览状态。

用户点开某一场后只自动读取该场双方详情，默认按蓝红阵营呈现十人记分板、队伍总量与资源计数；列表不预取，重开与切标签复用缓存，失败保留个人摘要并允许重试。团队分析以同一尺度展示六项玩家贡献与有条件总量。时间线和出装符文共用一次另行明确读取的真实帧/事件，包含事件/玩家筛选、实际位置、带正负轴的经济差、购买/出售/撤销与QWER加点、完整主副符文。标签支持左右/Home/End键。单人/缺字段场景不伪装完整双方数据。


## BUG-0055：单场详情阅读

首页单条最近战绩原位打开该场对话框，保留首页模式/样本/页码，关闭返回原按钮；“完整战绩”独立进入玩家工作区。详情随内容取高，长记分板内部滚动，不压缩首页卡片。复用现有深浅主题、官方英雄/技能/装备与品牌图标，无新依赖或竞品素材。

战绩展开分为对局概览、团队分析、时间线和出装符文。默认双方记分板按阵营分组，显示胜负/击杀、英雄与玩家、双技能/符文、KDA/参团、伤害与承伤、补刀/金币、视野和七个装备槽；伤害条以本场最高伤害为基准，团队占比仍要求完整5v5。点击单场后只自动读取该场双方资料，不因切主题或渲染重复请求；读取失败时个人终局摘要仍可查看。

赛后无赛前房间时不提供失效的展开按钮，改用阶段说明。选人时不把未读完误写成无记录；预选、锁定与换英雄只切已有统计，准备进度展示真实已读场数。

## 分阶段游戏助手与赛后分析（BUG-0054）

当前采用客户端侧栏、局内快览、主程序赛后分析三种场景，替代下文把主程序对局室作为实时名单的旧入口。侧栏与快览复用一个辅助窗口，默认左侧/320逻辑像素，与客户端同高；空间不足右侧，再不足折叠为28逻辑像素窄入口，主动展开向内覆盖。侧栏房间只显示实际我方成员；选人显示我方英雄和统计，不画敌方占位。摘要保持清晰字号，720高默认可看五人；完整统计通过语义details展开，卡片不因详情压缩。客户端最小化/切后台时隐藏，点击侧栏本身仍可操作。

开局只在实际InProgress、游戏前台且已有名单时自动展示一次6秒，最多等待开局45秒；初次辅助前端渲染就绪后再显示，迟到创建复查阶段和前台。自动/按住均穿透且不激活；自动期间按住键转hold，松开隐藏，倒计时不误关hold/手动模式。切出、结束、断线关闭临时状态，重连和资料更新不补弹。局内继续保持1100×640、236px十人分区卡与400×360可滚动两列，读数至少11px；排位赛季胜负分行避免半卡裁切。

主程序对局室展示“赛后分析”：本局结果与赛前资料分栏切换。赛前资料的单双排/灵活切换及缓存战绩筛选仅作用于这份复盘，不改当前侧栏/快览；查看记录不自动请求资料。查询最新战绩为明确动作，打开玩家战绩工作区。结算未同步与真实本局结果分别显示，不以赛前历史冒充本局KDA/胜负；新房间不覆盖上一局。首次无记录时给出侧栏/快捷键使用说明，不再重复实时十人名单。首页当前状态和主栏游戏助手入口沿新流程。设置游戏辅助增加侧栏开关、宽度和开局自动展示开关，仍统一显式保存、恢复默认只改草稿。

实现、预算与原生验收边界见 [COMPANION.md](COMPANION.md)。

## 可读性、统计状态与操作分组（BUG-0053）

沿用深浅主题、C 款图标、统一顶部栏与十人分区卡。RosterProgress 同时呈现真实名单身份数、近期战绩数和独立排位统计完整数；完整统计必须有当前模式，且当前赛季/12小时/30天均覆盖，不用近期历史的 readyCount 替代。部分覆盖、准备中、旧统计单独标注。快览的时间来自 ScoutReport，混合时间显示范围，缺失不由当前时间或历史时间补齐；段位仍按各自资料时间。

对局卡保持上下五人比较，主卡 300px、快览 236px。核心数值加大，辅助文字使用至少11px，去掉圆环内重复英文短标签及第三枚重复30天场次标签；30天汇总保留KDA与覆盖状态，胜率/有效场次在圆环呈现。英雄本季全模式场次与英雄熟练度各自标明，不给熟练度套赛季口径。低记录数不推断未使用或不熟悉。卡片仍为单一选择按钮，详细范围/位置分布可在玩家浮层的“本局统计说明”通过键盘展开；按住快览的核心值无需悬停。

首页常用英雄仅1–2位时整体切成两栏加紧凑英雄横条，主要行边缘对齐，避免把说明固定在空容器底部。窄窗压缩账号概览和段位行，跳页保持可见。战绩页保留原画，并提供无请求的收起/展开资料；窄窗玩家详情以横向身份摘要置顶，不改变后台名单卡片尺寸。单场详情的技术说明收进可展开说明。

设置按外观/游戏辅助/诊断与关于切换，支持方向键/Home/End。外观即时保存，游戏辅助统一显式保存、恢复默认仅改草稿；展示实际生效值、未保存状态和失败后实际结果，部分保存不冒称全部回滚。诊断与版本留在诊断区。

首页资料请求占用既有查询通道时，用户可提交一条可取消的等待查询；完成当前有界操作后执行。修改输入、断线或换连接取消等待；页面不新增接口、自动批次或持续刷新。浅色文字使用主题语义色，关键状态以文字与颜色共同表达；浅色正文对比以4.5:1为核对目标。


## 统一顶部栏（BUG-0052）

主窗口只保留一条 64px 顶部栏：左侧一份 Logo/产品名称，中部导航、查询与主题/功能入口，最右侧为最小化、最大化/还原和关闭到托盘。移除独立的小 Logo 标题行，窗口控制内嵌于产品界面。窄窗优先压缩间距和辅助文字，搜索与窗口按钮保持可用，不换行或裁切。

空白/品牌区域允许拖动和双击最大化；导航、输入、选择器、按钮及整个查询表单使用 no-drag，双击输入或导航不得切换窗口状态。输入支持正常选字。设置/玩家详情弹出后顶部业务区域与主工作区均 inert，窗口控制仍可使用且不抢弹窗焦点；遮罩从顶部栏下缘开始。

## 应用图标（BUG-0051）

正式使用用户选定的 C 款黑绿珐琅侦察员，不对称折耳与警觉眼神为固定视觉特征。标题栏、导航、快览和 Windows 资源使用同一套派生图，保持完整比例和透明外沿；移除旧字母 P、切角裁切及主题强调色底板。图标不改变已确认的深色紫色强调、浅色橙色强调。定稿与生成、资源校验和 DPI 验收边界见 APP_ICON.md。

## BUG-0050 当前规范

本节与 SCOUTING.md 替代下文 BUG-0048/0049 的近20场对局统计、占位段位徽记和固定首页样本。深浅主题继续保留。控件集中 controls.css：圆角按钮/模式分段按钮、明确悬停/按下/选中/禁用/键盘焦点，细圆角滚动条移除原生箭头。标题栏保留Windows按钮顺序与原生功能。

首页采用高清横版原画与渐变，三栏边缘对齐；当前账号的模式、10–50场分析、20场分页/跳页、继续/停止独立于查询与对局详情。近期表现和常用英雄随分析范围变化，翻页不改变统计样本。首页、查询档案和对局卡统一使用Riot官方段位PNG，未知显示占位横线，不能冒充未定级。

对局室顶部单双排/灵活统一切换，默认跟随当前排位对局；两队顺序不变。卡片的英雄经验使用独立当前赛季全模式场次及真实熟练度等级/分数，英雄排位K/D/A、胜率按选定排位；12小时/30天和30天位置分布只用该排位。读取尚未覆盖完整窗口时标已读范围，不能显示完整累计；无英雄近期记录不解释为不熟悉。缺少可信累计值时隐藏指标，不显示“累计数据暂不可用”。快览使用相同缓存与模式，按住时只读。

## 首页与外观（BUG-0048）

主窗口默认打开“首页”，横向导航为首页、对局室、玩家战绩、游戏辅助。首页按已核验的当前账号显示账号头像、等级、完整 ID、单双排/灵活排位、首批最近 20 场的胜率/汇总 KDA/近五场结果、最近五条战绩和最多五位近期常用英雄；赛季胜负只用来源实际返回值，常用英雄明确为近期样本。点击完整战绩或记录进入已有战绩页，不自动翻页。连接未就绪、资料准备中、无历史、来源失败和断线保留分别显示，不假造段位、记录或评分。

外观命名为“浅色”“深色”“跟随系统”，不按时间强制切换。浅色沿用暖纸白/墨色/橙色；深色参考 OP.GG Desktop 的炭灰背景与紫色强调，胜负保留文字，主题不复制竞品品牌或素材。默认深色；已保存的浅色或跟随系统选择优先，未选择、无效配置或存储不可用时回退深色。顶部选择和设置里的三种预览都立即生效，本机持久化选择，跟随系统响应外观变化，窗口间同步。存储不可用时仍可切换并提示无法保存；首次绘制前解析选择，避免深色启动时闪白。局内快览保持深色，符合游戏中阅读需求。

主题覆盖标题栏、首页、导航、战绩、详情浮层、设置、输入、提示与禁用状态；对局卡按主题切换分区背景，玩家海报保留深色渐变保护文字。首页在 1280/1100 宽度使用段位、近期战绩、常用英雄三栏，880 宽度将段位和状态排到上方，下方内容自然滚动，不缩小关键文字。

## 视觉与信息层级（BUG-0045）

正式界面支持默认炭灰/紫色深色与暖纸白/墨色/橙色浅色，以横向导航组织首页、对局室和战绩。对局卡以用户图一的分区对照形式为准，主工作区保持清晰的文字、筛选和记录阅读。参考 [OP.GG Desktop](https://op.gg/desktop/en/games/lol) 和 [Porofessor](https://porofessor.gg/download) 的玩家信息层级，不复制其品牌、代码、专有评分或示例资料。未知值保留未知，胜负同时使用文字和颜色。

主窗口为无边框外壳，64px 统一顶部栏跟随玩家选择的浅色/深色，保留原生拖动、缩放、最大化／还原和关闭到托盘；同栏提供首页、对局室、玩家战绩、游戏辅助、完整 ID 搜索、主题、设置和手动快览。原生主窗口默认 1280×800，最小 880×620，旧设置中的有效尺寸保留。

## 游戏辅助页与自动化提示（BUG-0085）

自动化不再是设置弹窗里的隐藏分组：导航第四项“游戏辅助”（窄窗显示“辅助”）进入独立工作区，包含自动接受与赛后流程两张卡片，开关、延迟与保存都在这里，设置页只保留到该页的入口，避免两处编辑同一状态。

## 两种快览

默认 1100×640 的深色快览为上下两排、每排五人，使用同一份分区卡和统计，卡高 236px，缩减辅助层并显示最多两个事实标签；不根据横向列声称实际位置匹配。最小 400×360 可纵向滚动，680px 以下改为紧凑两列；不为挤进十人而制造横向裁切。

- 临时：默认按住 Esc 下方的 `~`/反引号物理键（无需 Shift），松开隐藏；可在设置选择 F8/F9/F10 或关闭。仅连接中、InProgress 且实际 League of Legends.exe 窗口在前台时有效。鼠标和原始按键继续交给游戏，快览没有操作按钮，不抢焦点。切出游戏、离局、断线、改键、禁用或退出清理临时状态，首次创建期间松键也不迟到显示。
- 手动：按钮或 Ctrl+Shift+P 显隐，可交互、拖动、Esc 隐藏、切换置顶。置顶只表示 always-on-top；松开按住键不关闭手动快览。临时快览使用游戏所在显示器，隐藏后恢复手动窗口保存的位置/大小。

显示/隐藏均只读取缓存，不请求战绩、段位、头像或后续页，不重置每局的一轮补齐。按键冲突由用户在设置改键，不抢占游戏绑定；建议无边框/窗口模式。独占全屏、Windows DPI、多屏和游戏焦点的最终表现仍需实机验收。
