# 本局英雄攻略（BUG-0072）

用户已批准接入OP.GG官方MCP。Go直接访问`https://mcp-api.op.gg/mcp`，不要求安装Node、MCP工具或大模型。客户端仅发送英雄、分路、模式和zh_CN语言；不发送任何PUUID、玩家名、房间、客户端授权或比赛编号。无自建服务器，仍需要联网。

## 范围与入口

主程序当前对局默认紧凑攻略摘要，可展开完整攻略，客户端侧栏新增玩家资料/本局攻略切换，手动局内快览可切换查看缓存的核心装备、符文与至多两条要点，默认及按住/开局快览仍展示完整双方卡片，不因新增攻略挤掉十人名单。选人未确认/仅预选不查询；分路缺失时请用户选择，不从英雄猜分路。已有明确分路时尝试匹配唯一同路对手，可手动改选实际敌方英雄；重复分路不自动匹配。对手从当前名单消失时清除旧选择。所有窗口通过有序revision内存事件共享一份结果；切主题、显隐、页面与重复快照不请求OP.GG。

队列420/440/450分别映射ranked/flex/aram，mapId/gameMode明确冲突时拒绝映射；400/430/490显示排位来源的峡谷参考，非该模式专属统计。海克斯大乱斗、竞技场及其他队列不按地图猜成普通大乱斗。接口虽声明urf/nexus_blitz，本批未启用这两种尚未验证模式。普通大乱斗的工具协议强制position，内部固定mid作为请求占位，界面不把它显示为推断分路。分路对位工具无模式参数，仅用于单双排峡谷参考；灵活只使用独立flex分析，不能将无模式的对位正文包装成灵活专属攻略。

## 数据与执行

`internal/guides`包含固定MCP初始化/只读tools/call协议、响应归一化和独立Service。基础分析与对位分别加载，先显示已有基础内容，再补正文。每内容任务整体8秒、单HTTP5秒；当前查询稳定800ms后才开始，旧选择/账号/连接/对局/阶段变化取消并拒绝迟到发布及缓存写入，最多2个网络任务占位。30秒失败冷却，显式刷新也不突破冷却；无自动失败循环和批量全英雄扫描。与玩家战绩scheduler及自动接受/赛后动作通道独立。

MCP响应可能为JSON或“class字段定义＋位置构造器”的压缩文本。压缩解析器仅支持声明过的构造器、列表与标量，限制大小2MiB、深度64和节点10万；不执行返回内容。工具文本通过Vue转义呈现，不使用v-html。返回的样本缺失保持未知，已知零胜率保留零。技能整数槽位转换Q/W/E/R，中文物品/符文名由服务提供，本地官方图标缺失沿既有占位。

英雄英文映射由已有Riot Data Dragon头像manifest生成并处理命名差异；新英雄需更新随包映射。缓存只保存归一化公共攻略，查询包含mode/champion/position/opponent/客户端patch（可空）；实际来源版本保留在结果。内存/磁盘最多128条，每条256KiB，6小时新鲜度、超过7天丢弃。缓存先显示再后台更新；版本明确不同时提示差异，不能称为当前版本攻略。服务接口不接受指定历史版本，本地patch未知时如实标来源版本。无源码/文章/视频批量复制，保留OP.GG来源和原文链接。

## 验证与限制

单测覆盖受限文本解析、恶意/异常响应拒绝、JSON/SSE握手、字段和授权隔离、模式变体拒绝、缓存复用/失败保留、未知分路、对手合法性、重复快照、晚到请求与换连接。

可显式运行`LEAGUEPINGO_TEST_OPGG=1 go test ./internal/guides -run TestLiveOPGG -count=1 -v`核验公共服务，不读取游戏客户端。本批已实调ranked/flex/aram，以及GALIO对AHRI的mid攻略，中文装备/符文和对位正文归一化成功。真实网络结果只证明本次服务可用，不保证所有英雄/对位均有足够样本。

浏览器`frontend/tests/guides.cjs`为合成桥接，验证280侧栏与880/1280主窗、主题、来源/样本、备选方案、失败缓存保留、模式不可用、位置操作、跨窗事件和分组标记。Windows原生外链、选人换英雄、客户端版本字段覆盖及真实游戏体验仍需实机验收；本批Linux不交付exe。
