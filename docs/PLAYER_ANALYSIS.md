# 玩家概览与战绩分析重构（BUG-0059）

本批依据用户提供的九张参考图，沿用 LeaguePingo 的 C 款图标、统一控制栏、炭灰紫色深色与纸白浅色主题。参考的是数据组织、密度和阅读顺序，不复制竞品评分、AI结论、专有标签或页面素材。

## 数据与交互约束

- 概览回答“这名玩家最近表现与擅长什么”，战绩列表回答“这几场怎么打”，详情回答“这一局为什么值得复盘”。标题与最大数值对应各自问题。
- 首页只代表已核验当前账号；查询别人不替换首页。主窗口与赛前/局内辅助数据保持隔离。
- 排位聚合、近期筛选样本、7天已读记录、全部模式熟练度是四种范围，标签不能混用。筛选、翻页和切详情标签不重置原独立ScoutReport。
- 保留原模式/10–50场/继续查找/停止/分页/跳页/失败保留/离线缓存和首页单场原位查看。身份未知、字段缺失和真实零分别处理。
- 双方详情沿用显式按需、原串行调度和12秒手动预算；时间线只在明确请求时读取并有界缓存，无后台逐场扫描、渲染查询或定时轮询。换号/连接变化拒绝迟到结果。
- 跨多个赛季的完整段位轨迹、历史LP变化、OP评分、对线评分与AI标签目前没有已核验来源；仅呈现响应中可验证的最高/上一季记录，不能用当前段位冒充历史。

## 验证与保留边界

- 保留现有C款标志、统一控制栏、Segoe UI系统字体、深浅主题；Taste方向/seed见上文。信息签名为按同一记录展开的十人阵容、数字列与可切换复盘，未引入竞品评分。
- 1280×800仍核对五条完整战绩，1100×760至少四条；880×620无主页面水平溢出，详情内的十人表保留有标识的横向滚动。各模块不以压缩字号或截断卡片换取密度，辅助名单/轴标为11px，主体英雄/队列13px、KDA14px、概览主要读数19–21px。
- 符文/地图完全本地，浏览器回归阻断并检查所有外部请求；渲染、模式/主题/标签/布局切换不新增游戏查询。测试中的姓名、战绩与帧均为合成夹具，生产界面只消费实际返回的Participant和MatchDetail/MatchTimeline。
- 自动视觉探针的紫色限制按用户既有品牌明确豁免；半透明白色边线被探针当作不透明白色而报强边框，实际合成对比约1.4:1。独立纵向资料列不是同一行等高卡片，不能为对齐不同内容而拉伸空白或压缩段位。重复名单和轴标使用11–12px是本批密度取舍，重要指标已加大。已在真实浏览器逐图核对，完整本机critique留在忽略的设计证据目录。
- 工程/合成浏览器/Windows目标编译的结果见BUGFIX_LOG；Windows完整验证与真实国服对照仍按ACCEPTANCE执行。未获取的多赛季完整轨迹、历史LP或专有分数不显示为真实数据。
