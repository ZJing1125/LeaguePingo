# 性能验证与边界

## F1：本地诊断度量

本轮增加采集能力，没有新增真实国服对局或FPS测量结论。数据仅在本次运行内聚合，用户显式“导出诊断”时写入本机JSON；不自动保存原始样本或上传。

| 导出字段 | 口径 |
| --- | --- |
| `info.requests.<分类>.p95Ms / recentSamples` | 每个固定请求分类最近最多256次的nearest-rank P95，单位毫秒，包含失败请求；无样本为null，真实0保留。SGP各通道独立，含sgp-group；不是合并所有通道的P95或网络RTT。次数/失败/总耗时/最大耗时仍为本次运行累计。 |
| `performance.champSelectFirstData` | 从助手首次观察ChampSelect，到首次发布包含我方有效近期战绩（包括已确认空列表）或独立统计的快照。只出现姓名/头像不算；重复快照只计一次；已退出/断线/换连接/换号不记录为0，而计abandoned。资料时间早于入口计preexistingResults，包含房间预取与缓存；不是纯网络请求耗时或前端绘制完成时间。 |
| `performance.keyboardCallback` | 回调自身的调用数及total/mean/max微秒，排除CallNextHookEx下游链路。仅用时钟与原子计数，不保留键值、扫描码、按键顺序或原始事件。没有启用或尚无事件时meanUs为null。原有前台进程检查尚在回调内，S1仍待处理与国服实测。 |
| `performance.inGameResources` | 确认InProgress时取助手及其可读后代（含WebView2）的计数，首个样本只作CPU基线，此后约5秒一次。导出整机归一CPU最近/按有效观测时长加权平均/峰值、私有字节与工作集最近值/峰值、样本与失败计数、采集耗时。CPU首次为null，真实空闲区间为0。 |

资源采样复用`cmd/perfprobe`抽出的`internal/processstats` Windows原生计数代码；探针命令及CSV格式不变。计数读取在应用锁外，最多读取256个助手树成员，读取失败或截断计partial；上一端点缺失也会标记对应CPU区间为lastPartial。PID加创建时间仅用于内存中的相邻CPU基线，阶段退出即清除，不导出PID、创建时间、进程名、路径或命令行。新进程首个区间不补累计CPU，PID复用不产生尖峰。

非InProgress无周期OS采样；阶段切换清CPU基线，迟到结果按epoch丢弃，退出取消且不能被迟到快照重新启用。保留本次运行内已取得的汇总和lastAt，资源active=false不表示历史采样为当前值。未运行或不支持时计数为0、最近数值为null，不能写成测得0开销。工作集会重复计共享页，可读子集、5秒间隔和短命进程遗漏意味着结果不能替代完整A/B实测。

本轮验证：改动前`go test ./internal/...`通过；新增窗口淘汰/P95零值/并发导出、选人首结果与取消、无锁回调计数、资源CPU计算/PID重用/空闲/停止/迟到/缺失的回归，以及Windows原生资源计数测试。Linux执行通用与竞态检查；Windows执行及构建结果以该提交的CI记录为准。CPU/内存实测数据须由游戏电脑实际运行后导出，F5与R1保持未完成。

2026-10-18 产物治理说明：按用户批准的双版本规则，以下旧版原始性能 CSV 已永久清理，历史数值与验证范围保留作为当时记录，不再提供原始文件复核。v9/v8 当前仅保留对应合成界面截图，不能用旧记录代表新版性能。8 份隔离实例配置未改动。

## 可复现工具

在 Git Bash 配好 Go 后：

```bash
# 启动隔离隐藏离线实例，并采集整个进程树
go run ./cmd/perfprobe -exe bin/leaguepingo-dev-20261018-v9.exe -out bin/performance-offline

# 包含已创建但保持隐藏的快览
go run ./cmd/perfprobe -exe bin/leaguepingo-dev-20261018-v9.exe -open-overlay -out bin/performance-overlay

# 对现有助手做只读采样，替换 12345 为实际助手 PID，不是游戏 PID
go run ./cmd/perfprobe -pid 12345 -seconds 120 -scenario champ-select -out bin/performance-pregame
```

工具使用 Windows 原生进程快照、CPU 时间和内存计数，不读取启动参数或进程内存内容，不抓包、不注入。程序不会停止原有进程。当前系统禁止执行 PowerShell 脚本，未更改或绕过该执行策略；因此使用原生 Go 工具，而不是修改系统安全设置。
