# 双方当前对局分组（BUG-0071）

目标为双方全部玩家的真实组队关系。本批实现客户端明确分组标识的采集、关联、展示与匿名核验工具；国服不同模式中teamParticipantId的语义与完整覆盖尚待游戏电脑对照，不把结构成功宣称为真实组队识别验收完成。

## 来源与限制

已有GET /lol-gameflow/v1/session解析teamOne/teamTwo中的teamParticipantId和显式selectedPosition/assignedPosition，无逐人请求。非零、已知身份、同阵营的相同标识形成2–5人组；唯一标识与缺失标识均不直接断言单排。标识按阵营隔离，0/负值/缺失不能归为共同组。

组队标识不完整时，在加载/局内每连接/账号/对局最多一轮SGP补取：整个任务6秒，最多2次，每次2秒，间隔1秒；不等待战绩或读取历史。不新增局内持续轮询。与现有历史互斥锁隔离，独立瞬时凭据/请求，沿用客户端提供且严格核验的当前腾讯大区域名。GSM使用league-session token，不能使用SUMMARY战绩的entitlements token。

固定GET /gsm/v1/ledge/region/{当前platform}/puuid/{已核验本人}，只读取返回的game节点；game.id必须等于当前比赛，当前账号必须在双方名单中。Engine再按当前已有玩家身份与阵营逐一关联，不用此接口替换名单或解匿名。阶段/连接/账号/对局变化取消，迟到结果不得写入当前局；同局重新创建名单复用已读组标识和明确位置；SGP元数据可先保留在内存，只有LCU当前名单明确返回该身份且阵营一致时才显示，迟到身份不导致逐人重查。只对已列明标准队列420/440/450/400/430/490展示，其他模式留待语义验证。

## 展示和保留

玩家卡以“同组匿名码 · N人”展示来源分组，提示中明确国服语义待实机核验；当前对局显示已返回字段覆盖人数。侧栏/快览共享Participant，不改变玩家排序；当局冻结复盘保留当时的来源分组。原始teamParticipantId仅存在本局Go内存，JSON不导出；前端得到按账号/连接/比赛/阵营隔离的SHA-256匿名组码及同局稳定的A/B标签。组关系不写入磁盘历史、设置或诊断，也不使用历史共同对局推断来填补本需求。

## 实机核验

游戏电脑在加载/局内执行`bash scripts/audit-current-groups.sh`。入口严格要求Windows amd64，10秒只读有界核验；读取前后阶段、账号及比赛均应一致。输出仅为LCU/SGP覆盖人数、阵营、匿名槽位、组编号和组人数，无PUUID、姓名、鉴权、原始响应、游戏服务器地址或其他playerCredentials。该报告仍只是来源结构证据。

将每侧槽位与已知真实队伍名单对照，至少覆盖单双排、灵活2+3/五排、普通匹配和大乱斗，以及单排与多人组队混合、双方相同数字ID、缺失/0字段、账号切换和新比赛。敌方必须有独立可核实的组队基准；自定义房间只验证解析，不能代替匹配组队语义。记录正确组/错误合并/错误拆分/未知人数及覆盖率。未覆盖双方所有玩家不能称为全量完成。

自动回归覆盖同阵营分组、原始标识不导出、未知不补单排、SGP比赛/身份校验、双方关联、一次任务和迟到隔离。实际语义未验证前保留“同组”而非“已确认双排”的文案。

来源参考：LeagueAkari computed-state.ts的getLiveTeamParticipantGroups、additional-info-controller.ts及sgp/gsm.ts（56cdfde00e56148f4641d1a8cf86acb66e903124）。本批独立实现，无运行依赖或源码复制。

P1后续核验包含海克斯大乱斗2400：现有匿名Windows审计入口可以读取其当前LCU/GSM结构；在真实双方组队语义和覆盖率验收通过前，engine仍不开放2400的分组标记。当前Linux无游戏客户端与双方真实组队基准，不能完成该验收。

## BUG-0074：第二批工程补齐

修复第二次部分GSM响应覆盖第一次元数据的问题，迟到身份沿用同局已取得的标识；来源标签覆盖单个标识，不因尚未形成多人组而误标LCU。core.MergeGroupFields供产品/核验共用身份、阵营、重复和标识冲突检查，不能补入名单尚未公开的身份。

可显式执行`bash scripts/audit-current-groups.sh --expected 本机槽位基准.json`。文件最多4KiB，形如`{"queueId":440,"groups":[1,1,2,2,2,1,1,2,3,4]}`，顺序为当前审计输出的1–10槽位（我方在前），同一数字只在同一阵营内表示真实一起排队，不同数字表示已核实分开排队；单人也必须独立分配正数。文件不含姓名/PUUID/真实分组标识，不提交项目。需要独立知道双方真实组队名单；不能拿被测字段反过来制作基准。

核验仅在内存合并当前已公开名单与GSM元数据，输出known/10、同阵营20个玩家对的已比较数、正确同组、误合并、误拆分及未知对数。未知不算单排/正确。队列不符、少于十槽位、身份/阵营冲突或不完整/有误结果均失败；一次匹配基准只支持这一局的对照，不能推广为全部国服模式已验收。基准内容、截图、玩家信息和原始分组均不写报告文件或上传。海克斯的产品分组展示仍需真实语义验收后开放。
