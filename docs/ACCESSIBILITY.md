# 键盘与可读性

U7 当前覆盖桌面 WebView 的主流程，使用现有原生控件和 ARIA 标签；不新增依赖或全局按键监听。Windows 窗口、游戏焦点、屏幕阅读器、放大/高对比度系统模式和完整 WCAG 审计尚未验收。

## 键盘路径

`frontend/tests/player-analysis.cjs`在原有合成应用中调用`keyboard-access.cjs`：

- Tab/Shift+Tab 到达导航、主题、段位summary、战绩行、搜索、筛选、分析标签、设置和自动化开关。
- 回车/空格展开段位和记录；方向键/Home/End切换原生选择及分析/设置标签。
- 单场弹窗与设置循环保留焦点；Esc关闭并返回打开它的记录/按钮。
- 记分板滚动容器可获焦；切换标签不会隐式读取时间线，导航不启用自动化。
- 亮暗两主题均执行，全程只用真实按键驱动用户操作，读取DOM只用于断言；原有减少动态效果规则继续有效。

先生产构建，再设置现有浏览器的`BROWSER_EXECUTABLE`并运行`npm --prefix frontend run test:smoke`。既有入口不变；可按现有`UI_SCREENSHOT_PREFIX`保存两主题焦点截图，均为合成数据。

## 主题与焦点

共享控件覆盖button/input/select/textarea、summary、链接和tabindex=0滚动区域，使用至少2px焦点边框；战绩与滚动容器内收，避免裁切。`:where`保持共享规则低权重，组件既有状态仍可局部控制。不使用!important或删除减少动态效果规则。

当前回归测量核心语义色，按sRGB相对亮度计算；正常文字阈值4.5:1，焦点与实际背景阈值3:1。实际祖先背景和焦点宽度/颜色由浏览器计算，不只统计源码中有多少ARIA属性。

| 语义色对 | 浅色 | 深色 |
| --- | ---: | ---: |
| 正文/面板 | 13.88:1 | 13.15:1 |
| 次要文字/面板 | 5.56:1 | 6.59:1 |
| 强调文字/面板 | 4.80:1 | 6.59:1 |
| 胜利文字/胜利行 | 4.81:1 | 6.76:1 |
| 失败文字/失败行 | 4.61:1 | 6.74:1 |
| 主按钮文字/背景 | 4.88:1 | 5.87:1 |

这些结果只覆盖表中语义色和测试所走控件，不能据此声称所有图表、游戏图片或辅助技术均已达标。产品数据、取数预算、默认关闭自动化和窗口显隐政策不因键盘样式改变。
