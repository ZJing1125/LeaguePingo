## 本轮已经完成的非实机回归

- 全量 Go 测试/静态检查、绑定生成、TypeScript/生产构建、Edge 合成绑定交互通过。
- 布局：1280×800 至少五条完整战绩；880×620 无根级横向溢出；540×660 十人已就绪可见，指标标签与近况不重叠；最小快览 400×360 可纵向滚动，不横向裁切或叠字。默认装备/技能不触发整场请求。
- 状态：查询失败保留；首次历史失败仍能重试；切换玩家不串错；资料字段时效与迟到旧快照、同连接换号及重连名单预算均有回归。
- 阶段：本地 TLS WebSocket 合成服务覆盖单主题、去重/过滤、取消、拒绝重定向；引擎覆盖通知取消预取、旧来源隔离、冷却和轮询回退，相关 Go 测试重复二十轮通过。这不是国服主题支持的证据。
- 隔离的隐藏原生双进程测试已通过：重复启动退出并通知已有实例，隐藏窗口位置与鼠标输入检查正常。不结束真实助手/游戏，不代替前台悬浮实测。

合成截图 `bin/ui-final-{players,match,overlay}.png` 仅本地保存且已目视复查；身份和统计是测试样本，不是线上查询结果。真实游戏、本机窗口缩放/多屏或竞品同尺寸对照未通过这些测试自动完成。

## 性能记录

按照 PERFORMANCE.md，在相同分辨率/画质/游戏负载下对助手退出、局内隐藏、快览可见、显式查询至少各做三次测量。记录助手版本、游戏版本/模式、帧时间 P95/P99、平均 FPS 和游戏显示延迟，以及助手+WebView2 进程树 CPU/私有内存、持续时间和请求量。仅比较可复现负载，不能用不同自然对局简单归因。

进程树工具：`go run ./cmd/perfprobe -pid <助手PID> -seconds 120 -scenario in-game-hidden -out bin/performance-live`。该工具不会测出游戏 FPS 或网络 RTT；不要把 CSV 填进这些指标列。正式通过与否根据测量和用户可接受阈值决定，缺证据保持待测。
