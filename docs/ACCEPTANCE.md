# 国服实机验收

前轮环境：2026-10-16 显式阶段探测未发现 LeagueClient/LeagueClientUx；2026-10-17 用户提供实机界面反馈，本批据此修复模式、刷新、分页和样本交互。新版修复未代替下列真实链路复验。无需为了验收自动操作或替用户进行游戏。

## 准备

在 Git Bash 配置 README 的工具路径，从托盘退出旧助手后打开新测试版，在“设置与诊断”核对提交号。先执行 `bash scripts/verify.sh`；该命令使用合成玩家，不连接账号。

2026-10-18 交付程序：`bin/leaguepingo-dev-20261018-v6.exe`，内嵌提交 `aa59417`。统一验证和该提交的完整构建已通过；文档后续提交不改变程序中的版本号。本轮可先在大厅完成以下复验：

1. 查询一个在当前大区有足够近期记录的玩家，选择全部模式和 50 场，核对实际/目标数量及列表里的日期、比赛编号确实扩展到首批之外。
2. 切换灵活排位，依次检查 10/20/30/40/50 样本；已取得数量应随真实记录增长，统计只用此模式。出现“继续查找”时继续同一目标；若达到可查询范围或服务受限，按提示区分，不能要求不存在的样本被填满。
3. 输入第 3 页并回车，检查页码、范围与比赛变化；返回缓存完整页后不应重新加载。尝试非法页码，确认保留当前页并提示；远页扫描暂停后继续应仍指向所输入页。
4. 检查主窗口和对局玩家抽屉的分页均位于战绩面板内；刷新战绩只刷新当前历史，顶部查询按钮不进入查询中，列表回到第一页，保留模式与样本选择。

## 真实分页证据（2026-10-17 / BUG-0031）

用户复验发现首批以外始终只有 20 场。只读复现 LCU 请求起始 0/20/40 均返回同一首页，不应视为历史耗尽。接入 SGP 后显式运行 `LEAGUEPINGO_LIVE_PAGING_TEST=1 go test ./internal/source -run '^TestLiveHistoryPagination$' -count=1 -v`，非选人/对局阶段通过：初始 20 场加五页新增 100 场，共 120 场不同比赛，新增含 20 场灵活排位。此检查不存身份/响应；进入选人/对局会停止。结论只覆盖当前账号与大区的数据层，不替代界面、其他账号、多区或性能验收。

## 性能记录

按照 PERFORMANCE.md，在相同分辨率/画质/游戏负载下对助手退出、局内隐藏、快览可见、显式查询至少各做三次测量。记录助手版本、游戏版本/模式、帧时间 P95/P99、平均 FPS 和游戏显示延迟，以及助手+WebView2 进程树 CPU/私有内存、持续时间和请求量。仅比较可复现负载，不能用不同自然对局简单归因。

进程树工具：`go run ./cmd/perfprobe -pid <助手PID> -seconds 120 -scenario in-game-hidden -out bin/performance-live`。该工具不会测出游戏 FPS 或网络 RTT；不要把 CSV 填进这些指标列。正式通过与否根据测量和用户可接受阈值决定，缺证据保持待测。
