## BUG-0058 侧栏左侧空间足够时不得覆盖客户端

用户反馈100%缩放、单屏居中。旧策略可在宽度刚够但6像素间距放不下时复现；当前Linux只验证策略与目标编译，以下为Windows实际窗口复验。

1. 典型复现：1920宽工作区、1280客户端居中、默认320侧栏，两侧各320；自动侧栏及手动展开应在左侧X=0/宽320，侧栏右边不得越过客户端左边，客户端位置不变。不要为了留6像素缝隙改为覆盖或擅自缩侧栏宽度。
2. 分别从侧栏收起按钮/窄入口、主程序“展开客户端侧栏”反复收起再展开；留白宽度刚够、仅够部分间距、左侧刚够而右侧更宽时仍优先左侧外部。空间宽裕保留原6逻辑像素间距。
3. 左侧确实不足、右侧刚够时右侧贴边；真正两侧都不足时才使用原窄入口/显式内覆。移动客户端重新出现足够空间后应恢复外侧停靠。配置280/320/420宽度、125%/150%缩放、负坐标副屏分别核对，保持同高与屏幕内可达。
4. 检查跟随移动、最小化/恢复和侧栏交互焦点，显隐不触发玩家查询。游戏加载快览、按住与赛后资料预算沿用现有规则，不把本次几何验证当作真实整局/性能验收。
